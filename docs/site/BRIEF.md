# Public developer documentation brief

Maintainer: Jillur Rahman. Date: 2026-11-05.

Deliver a public source repository and fast GitHub Pages documentation at
https://developerjillur.github.io/ffmpeg-v2/. Main language: English, with original
Bengali technical reports retained and linked. Audience and evidence boundaries
are defined in [RESEARCH.md](RESEARCH.md).

Reader journey: see measured workflow improvements → understand what FFmpeg-v2
adds to Stock FFmpeg → choose an application/CLI/MCP use case → install → inspect
exact comparisons and methods. Internal phase chronology is secondary technical
archive content. The homepage and README lead with benefits and released-profile
results, with their baseline immediately visible.

Pages: overview; getting started; CLI reference; MCP; Python integration; benchmark
explorer; report archive; configuration; architecture; contributing; complete
rendered historical reports. Every page has a unique title/description, canonical
URL, source link and useful navigation. Add sitemap, social preview and factual
structured data. GitHub topics, README, issue templates, license, security policy,
citation and a source release support reuse and discovery.

Design: system sans-serif and monospace fonts, 1160px content width, generous but
compact spacing, 1px rules, restrained corner radii. Hero uses two columns and a
receipt/terminal illustration on desktop, one column on mobile. Benchmark controls
use native buttons and aria-pressed, leaving all tables visible without JS. The
report archive is searchable with a labeled input. No animations are required;
respect reduced motion for any short interaction transition.

Acceptance: source tests pass; no personal paths/secrets/runtime databases/binaries
in the public commit; genuine author and license notices; every report reachable;
no broken internal URLs; actual hosted deployment and anonymous access verified.
No universal speedup, official affiliation, PGO promotion, paid entitlement,
search ranking or trending claim.
