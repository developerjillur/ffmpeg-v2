# Discovery and sharing

Canonical project: https://github.com/developerjillur/ffmpeg-v2

Documentation: https://developerjillur.github.io/ffmpeg-v2/

The README and website describe the actual product with useful terms: FFmpeg,
local media workflows, macOS, Apple Silicon, Python, CLI and MCP server. The
repository's topics, description and homepage point to the same project. Unique
page titles/descriptions, canonical URLs, a sitemap, a social preview, structured
source metadata and static internal links help readers and crawlers understand it.
No hidden keywords, invented reviews, fake stars or engagement automation are used.

## Search indexing

The project sitemap is
https://developerjillur.github.io/ffmpeg-v2/sitemap.xml. Public pages are readable
without JavaScript. The project-level robots.txt links the sitemap, but crawler
rules are normally read from the hostname root /robots.txt; a project Pages
subdirectory does not independently control that root file.

Search engines decide when to crawl, index and rank a new site. Publication, a
sitemap and structured metadata do not guarantee indexing, rich results, ranking
or placement on GitHub Trending. No Search Console ownership verification or
sitemap submission is claimed. If the maintainer later verifies the exact site
property in Search Console, submit the sitemap there and inspect actual coverage.

## A truthful introduction to share

> FFmpeg-v2 is an independent macOS toolkit for typed local FFmpeg workflows.
> It combines a CLI, eight-tool MCP server, supervised queue and verified outputs.
> Source, setup guides and Phase 2–11 reports are public. The latest experimental
> PGO workflow result is scoped to one M4 Max workload; the candidate was not
> promoted because direct sample gates were incomplete.

Link the repository for developers, the getting-started page for setup and the
benchmark page when discussing results. The social-preview image is available in
site/assets/social.png. Share only where the community's rules welcome it, and
respond with reproducible examples and evidence. This publication does not post
messages or promotional submissions to other communities.
