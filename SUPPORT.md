# Support and project feedback

Read the [quick start](docs/GETTING-STARTED.md), [configuration](docs/CONFIGURATION.md)
and [limitations](docs/LIMITATIONS.md). For reproducible bugs and scoped feature
requests, use https://github.com/developerjillur/ffmpeg-v2/issues/new/choose.

Provide a small sanitized specification, source version and backend version.
Resource admission failures need their reason and current headroom, not a forced
rerun. Do not upload private/client media or secrets. Security reports follow
[SECURITY.md](SECURITY.md). Support is community/maintainer effort without an SLA.
